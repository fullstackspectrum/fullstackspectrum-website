Hello, world: why Full-Stack-Spectrum exists

Every security scanner speaks a slightly different dialect of JSON. Trivy, Grype, Snyk, OSV — they all tell you something is wrong, but rarely what to do about it first. Full-Stack-Spectrum is my attempt to close that gap with small, focused, open-source tools.

The toolbox so far

  • GitPulse — GitHub traffic and release analytics, with history that outlives GitHub's 14-day window.
  • Forgely — interactive security graphs for tracing blast radius and attack paths.
  • Vulnly — one self-contained, offline HTML report from any scanner's output.
  • Assay — OSV vulnerability summaries across workspaces and repositories.
  • Policy Insights — dashboards from policy decision logs.

Principles

Install in one line. Do one job well. Produce something a human can read.

That means shipping through the package managers people already use:

brew install fullstackspectrum/gitpulse/gitpulse
pip install vulnly
docker run -d -p 8000:8000 fullstackspectrum/forgely:latest
